# Manual QA Appointment Portfolio

A practical portfolio of manual test cases for a sample appointment booking workflow. The scenarios demonstrate clear test design, positive and negative coverage, boundary checks, and usability/accessibility considerations.

## Project contents

- [Appointment booking test cases](test-cases/appointment-booking.md): test scenarios, preconditions, steps, expected results, and execution notes.

## Scope and assumptions

This is a sample portfolio project, not a report of testing a production application. The booking workflow and its rules are stated in the test case document so the cases can be adapted to a real product. No execution results are claimed until the cases are run against an application.

## How to use

Review the assumptions, map the terms and rules to the target application, then record actual results and evidence during execution. Keep expected results independent from implementation details where possible.
